TPO POO (UADE) - Sistema de Gestión para Guarderías de Mascotas - Grupo 4
=========================================================================

Java 17 o superior + Swing + SQL Server (JDBC). El diseño original está en docs/Entrega_Parcial_1.pdf;
el modelo actual está en diagrama/Diagrama_de_Clases_Guarderia.puml (.png / .svg).


1. PREPARAR SQL SERVER (una sola vez por computadora)
-----------------------------------------------------
  a) Habilitar el usuario de SQL Server (autenticación mixta):
     SSMS > clic derecho sobre el servidor > Properties > Security >
     "SQL Server and Windows Authentication mode" > OK. Reiniciar el servicio SQL Server
     (SQL Server Configuration Manager > SQL Server Services > clic derecho > Restart).
  b) Habilitar TCP/IP en el puerto 1433:
     SQL Server Configuration Manager > SQL Server Network Configuration > Protocols for SQLEXPRESS >
     TCP/IP > Enabled. En TCP/IP > Properties > IP Addresses > IPAll: borrar "TCP Dynamic Ports" y poner
     "TCP Port" = 1433. Reiniciar el servicio.
  c) En SSMS abrir y ejecutar (F5), en este orden:
       bd/1_crear_base_y_tablas.sql   crea la base GuarderiaMascotas, el usuario "guarderia" y las tablas.
       bd/2_datos_de_ejemplo.sql      carga los datos de ejemplo (se puede volver a ejecutar para resetear).
  d) Si hace falta, cambiar url/usuario/clave en conexion.txt (está en la carpeta del proyecto).

  Las fechas de los datos de ejemplo se calculan desde el día en que se ejecuta el script 2.
  Conviene ejecutarlo de nuevo el día de la defensa.


2. ABRIR Y EJECUTAR
-------------------
  IntelliJ IDEA: File > Open > elegir la carpeta del repositorio. El proyecto ya trae la configuración
  (GuarderiaMascotas.iml y .idea/). Si pide SDK: File > Project Structure > Project > SDK = 17 o más.
  Ejecutar con la configuración "Main" (arriba a la derecha) o clic derecho en src/app/Main.java > Run.
  La carpeta de trabajo tiene que ser la del proyecto (para encontrar conexion.txt): la configuración
  "Main" ya lo trae así.

  Eclipse: File > Import > Existing Projects into Workspace. Ejecutar src/app/Main.java.

  El driver de SQL Server (lib/mssql-jdbc-12.8.1.jre11.jar) ya está en el proyecto, en los dos IDE.

  Al arrancar pide el legajo del empleado que va a operar. Legajos de ejemplo:
    101 Carla López (encargada de Belgrano)    102 Diego Pérez    103 Valeria Sosa
    201 Marcos Ibarra (encargado de Caballito) 202 Julieta Romero
  Todo lo que se hace queda en el log a nombre de ese empleado. Solo los encargados ven el log.
  Los avisos de incidentes (SMS al cliente y aviso interno al encargado) y el log se ven en la consola.


3. ESTRUCTURA DE PAQUETES
-------------------------
  app                 Main: estilo Nimbus, abre la interfaz con invokeLater, conecta y pide el legajo.
  vista               Menú (con JMenuBar), 4 ABM, Reservas, Estadías, VentanaLog, DialogoVacunas,
                      DialogoDetalleReserva y Validaciones.
  controlador         SistemaGuarderia (Controlador GRASP + Singleton): las pantallas le piden todo a esta
                      clase. Valida, guarda cada cambio en la base y escribe el log.
  persistencia        ConexionBD (lee conexion.txt y abre la conexión) y Repositorio (SQL con JDBC).
  excepciones         IngresoRechazadoException y DatoInvalidoException (checked),
                      ErrorBaseDeDatosException (unchecked).
  modelo.persona      Persona (abstracta), Cliente, Empleado.
  modelo.mascota      Mascota (abstracta), Perro, Gato, Conejo, Ave, Mascota.Vacuna (anidada estática).
  modelo.sucursal     Sucursal, Alojamiento.
  modelo.reserva      Reserva, Reserva.Pago (anidada estática), Reserva.RegistroDiario (clase interna),
                      ServicioContratado, Indicacion.
  modelo.log          EntradaLog.
  modelo.interfaces   Facturable, Vacunable, Notificable.
  modelo.enums        Especie, Categoria, EstadoReserva, TipoRegistro, TipoServicio, TipoIndicacion, AccionLog.
  bd                  Scripts SQL (crear base y tablas, datos de ejemplo).


4. LO QUE SE AGREGÓ PARA LA ENTREGA FINAL (pedido del profesor)
---------------------------------------------------------------
  Collar identificador
    Cada mascota tiene codigoCollar (COL-00001), generado desde el id (único en la base).
    Se busca por collar en ABM Mascotas, en Check-in/Estadías y en Menú > Operación > Buscar por collar.
  Servicios (baño, corte de pelo, corte de uñas, paseo extra)
    Enum TipoServicio (precio y a qué especies se aplica) y clase ServicioContratado.
    Se contratan en la reserva (suman a la cuenta) y un empleado de la sucursal los marca como realizados:
    queda quién y cuándo, y además un registro SERVICIO en la bitácora. No se puede hacer el check-out con
    servicios sin hacer. Se ve cuántos se contrataron, cuántos se hicieron, lo pagado y el saldo.
  Seguimiento de la estadía
    TipoRegistro ahora tiene COMIDA, MEDICACION, PASEO, SERVICIO, OBSERVACION e INCIDENTE.
    Cada registro guarda quién lo hizo (empleado de la sucursal) y, si corresponde, qué indicación del
    dueño cumple. La pantalla de Estadías muestra indicaciones, servicios y bitácora juntos.
  Indicaciones del dueño (comida puntual, medicación, cuidados especiales)
    Enum TipoIndicacion y clase Indicacion (descripción y horario), cargadas en la reserva.
    Para cada una se ve cuántas veces se cumplió, cuándo fue la última y quién la cumplió.
  Logs de todo
    Cada acción (ingreso, altas, bajas, modificaciones, reservas, pagos, check-in/out, servicios,
    indicaciones, registros y rechazos) queda en la tabla log_sistema con fecha, usuario y detalle.
    Pantalla "Log del sistema" (Ctrl+L): filtra por acción y texto y ordena (Comparator con lambdas);
    la consulta se hace con SwingWorker.
  Base de datos SQL Server
    Reemplaza los .txt. JDBC: DriverManager, Statement, executeQuery/executeUpdate y ResultSet.
  Correcciones
    No se puede pagar más que el saldo, ni hacer el check-in antes de la fecha de entrada o después de la
    de salida, ni cargar registros con un empleado de otra sucursal. Main usa invokeLater (regla del EDT).
